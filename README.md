
# Cybersecurity Analysis Tool

## Project Description
This project is designed to help cybersecurity analysts
analyze security logs and identify suspicious activity.

## Objectives
- Analyze security log files
- Identify failed login attempts
- Improve cybersecurity monitoring
- Use GitHub for version control
- Track security issues using Freshworks

## Technologies
- Python
- Git and GitHub
- Freshworks

## Branch Structure
- main: Production branch
- development: Development branch
- feature/*: Individual feature branches
